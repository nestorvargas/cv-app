# API Reference

All endpoints are prefixed with `/api`. In development, Vite proxies `/api` requests to the backend.

---

## CV Profiles

### `GET /api/cv`

List all distinct profiles.

**Response (200):**
```json
[
  {
    "profile_name": "desarrollador",
    "profile_label": "Desarrollador Full Stack",
    "personal_info": { "name": "Nestor Fabian Vargas Ferrucho", ... },
    "language": "es"
  },
  ...
]
```

Returns one row per profile (ES language).

---

### `GET /api/cv/:profileName/:lang`

Get a single CV profile by slug and language code (`es`/`en`).

**Response (200):**
```json
{
  "id": 1,
  "profile_name": "desarrollador",
  "profile_label": "Desarrollador Full Stack",
  "language": "es",
  "personal_info": { ... },
  "summary": "...",
  "experience": [ ... ],
  "education": [ ... ],
  "skills": { ... },
  "certificates": [ ... ],
  "profile_image": "/uploads/profile_123.jpg",
  "created_at": "...",
  "updated_at": "..."
}
```

**Response (404):** `{ "error": "CV not found" }`

---

### `PUT /api/cv/:profileName/:lang`

Update CV profile fields. Partial updates supported via COALESCE — only send fields that changed.

**Request body** (all fields optional, JSON):
```json
{
  "profile_label": "New Label",
  "personal_info": { ... },
  "summary": "...",
  "experience": [ ... ],
  "education": [ ... ],
  "skills": { ... },
  "certificates": [ ... ],
  "profile_image": "/uploads/photo.jpg"
}
```

**Response (200):** `{ "message": "CV updated successfully" }`

---

### `POST /api/cv`

Create a new profile. Inserts rows for both `es` and `en` simultaneously.

**Request body:**
```json
{
  "profile_name": "My new profile name (will be slugified)",
  "profile_label": "My Label"
}
```

**Response (201):** `{ "message": "Profile created", "profile_name": "my-new-profile-name" }`

The `profile_name` is generated by slugifying the input.

---

### `DELETE /api/cv/:profileName`

Delete a profile (both language rows).

**Response (200):** `{ "success": true, "message": "Profile deleted" }`

**Response (403):** `{ "error": "Cannot delete default profile" }` — protected profiles: `desarrollador`, `devops-linux`, `lider-tecnico`.

## PDF Generation

### `GET /api/pdf/:profileName/:lang`

Generate and download a PDF for the CV profile.

**Query parameters:**

| Param        | Required | Default        | Description                |
|--------------|----------|----------------|----------------------------|
| `template`   | No       | `"classic"`    | Template name              |
| `accentColor`| No       | template default | Hex color (e.g. `#1abc9c`) |
| `bgColor`    | No       | template default | Hex color (e.g. `#2c3e50`) |

**Response (200):** Binary PDF file download (`application/pdf`).  
Filename: `CV_NestorVargas_<profileName>_<lang>.pdf`

**Behavior:**
1. Launches Puppeteer (headless Chromium in Docker)
2. Navigates to frontend `/print/:profileName/:lang?template=...&accentColor=...&bgColor=...`
3. Waits for `window.__CV_READY__` to be set to `true`
4. Screenshots each `.cv-page` element at 2x device scale factor
5. Assembles screenshots into A4-sized PDF using `pdf-lib`
6. Returns the PDF as a download

**Errors:** 400 if Puppeteer launch fails, 500 on PDF assembly failure.

## Image Upload

### `POST /api/upload/image`

Upload a profile photo.

**Request:** `multipart/form-data`

| Field       | Type   | Required | Description                      |
|-------------|--------|----------|----------------------------------|
| `image`     | File   | Yes      | Image file (JPG, PNG, WebP)      |
| `profileName` | Query | Yes    | Profile slug to associate image with |

**Constraints:**
- Max file size: 5MB
- Accepted MIME types: `image/jpeg`, `image/png`, `image/webp`

**Response (200):**
```json
{
  "url": "/uploads/profile_1712345678.jpg",
  "message": "Image uploaded successfully"
}
```

The file is saved to `backend/uploads/profile_<timestamp>_<original-name>` and the path is stored in `cv_profiles.profile_image` for ALL language rows of the given profile.
